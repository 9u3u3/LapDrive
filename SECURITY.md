# Security policy

LapDrive gives a phone access to the files on a laptop. Please report security problems in private.

## Report a vulnerability

1. Open the **Security** tab of this repository.
2. Click **Report a vulnerability**.
3. Describe the problem and the steps to reproduce it.

Do not open a public issue for a security problem.

## Supported versions

Only the latest release gets security fixes.

## Security model

The README describes the security model in the [Security](README.md#security) section.
